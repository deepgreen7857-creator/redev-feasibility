# 정비경매 리포트 화면 — 남은 작업 (2026-10-22)

서버(수집·상세 해석)는 고쳐서 배포했습니다. 화면(React) 최신 소스가 이 PC(`C:\jbslab-auction\web`, 11:42 판)에 없어서
**화면 쪽은 최신 소스가 있는 곳에서** 아래대로 고친 뒤 빌드 → `auction/` 에 올리면 됩니다.

## 1. 물건 상세화면 순서 (DetailPage)
1. **물건 기본현황**: 사진 · 지번/도로명 주소 · 지목 · 용도 · 토지/건물 면적 · 감정가 · 최저가 · 유찰 · 매각기일 · 이용현황
2. **권리**: 임차인 · 등기 · 인수권리 · 법정지상권
3. **토지이용 · 정비구역 · 분양자격**
4. **판정 · 돈 계산 · 회차별 최저가**
5. **시세 근거**

- 사진 칸은 **항상** 표시. 자료가 없으면 `사진 없음(상세 수집 대기)`.
- 상세가 없는 항목도 칸을 숨기지 말고 `수집 대기`로 표시.
- 관리자에게 **「이 물건 상세 지금 받기」** 버튼 → 서버 함수 `fetchDetailNow({ listingId })` 호출
  - 돌려주는 값: `{ ok: true, listing }`(갱신된 물건 전체) 또는 `{ ok: false, message }`
  - 온비드 물건만 됩니다(법원경매는 수집기 자료).
- 분양자격 판단 줄에 **근거 값**(토지면적 · 용도 · 지분 여부)을 함께 표시.

## 2. 상세 자료 모양 (`listing.detail`, `detailVer: 2`)
실제 응답 항목 이름으로 바뀌었습니다(`auction-server/functions/src/lib/onbid.js` 의 `mapDetail`).

| 항목 | 뜻 | 비고 |
|---|---|---|
| `photos[]` | 사진 주소 | 원본 `potoUrlList` = `[{urlAdr}]` 배열 |
| `mapUrls[]` | 위치도·지적도 이미지 주소 | 원본 `lrmUrlAdrList` = `|` 로 이은 글자. 링크가 아니라 **이미지**로 보여도 됨 |
| `addressFull` / `roadAddress` | 지번 / 도로명 주소 | `zadrNm` / `cltrRadr` |
| `landCategory` | 지목(예: 대, 임야) | `sqmsList` 의 `토지>대` |
| `areas[]` | `{kind:'토지>대', area:'21.57㎡', share:'지분(총면적 …)'}` | 집합건물 대지권 지분도 여기 들어옴 |
| `appraisalDate` · `appraisalOrg` · `appraisalFile` · `appraisals[]` | 감정 시점·기관·감정평가서 | `apslEvlClgList` |
| `distributionDeadline` | 배분요구 종기 (YYYYMMDD) | |
| `requestOrg` | 위임기관(세무서 등) | |
| `bidMethod` | 전자입찰 · 일반경쟁 · 최고가방식 | |
| `usageStatus` · `location` · `deliveryDuty` · `cautions` · `conditions` · `extraNotes` | 공고 원문 글 | |
| `rights[]` | `{kind, holder, date, amount}` | 원본 `rgstPrmrInfList` (`irstDivNm`, `cltrInprNm`, `rgstYmd`, `inprStngAmt`) |
| `leases[]` | `{kind, tenant, deposit, rent, moveIn, fixedDate, claimed:null}` | 원본 `leasInfList`. **배분요구 여부는 API에 없음** |
| `superficies` · `survivingRights` | 유의사항 글에서 찾은 법정지상권 / 인수·대항력 문장 | 전용 항목 없음 |
| `rounds` | 항상 `[]` | 상세 API에 회차 목록이 없음 → 회차별 최저가는 화면 계산값 사용 |
| `flags` | `{superficies, survivingRights, tenants, tenantsUnknown, unclaimedTenants:null, qualification, share}` | `tenantsUnknown` = 이름만 있고 보증금·전입일이 빈 줄 수 |

물건 쪽에 새로 생기는 값: `pnu`(주소검색으로 찾은 경우 `pnuSource: '주소검색: …'`), `detailVer`, `detailEmptyAt`(응답이 빈 경우).

## 3. 관리자 화면 「API 연결 시험」
`온비드 상세` 줄이 추가됨. 지금 화면은 `sample` 글자만 보여 주므로 거기에 항목 이름 전체·사진/지도 형태·구분자를 넣어 두었습니다.
결과 객체에는 `fields`(항목 이름 배열), `shapes`(목록형 항목 모양), `media`(사진·지도 값 예시)도 있으니 화면을 고칠 때 표로 보여 주면 좋습니다.
