# 화면 시험 도구 (Playwright)

사이트를 로컬 서버(8765)로 띄우고 크롬으로 화면을 직접 눌러 보며 콘솔 오류·결과를 확인하는 스크립트입니다.

- `arch-ui.js` — /arch 배치안 → 위험요소 카드·정밀 검산·일조 연계 다듬기
- `decision-ui.js` — /arch 확정 → /decision 결정조서(구성·칸 고치기 저장·A4 PDF)
- `panel-ui.js` — /arch 확정 → /panel 판넬(A0)·팸플릿(A4) PDF
- `bird-ui.js` — 조감도

## 준비 (새 작업 공간)
```
cd tools/ui-test && npm install      # leaflet·leaflet-draw·turf 6.5·three 0.128 (CDN 대신 씀)
node decision-ui.js
```
- playwright는 작업 공간에 미리 깔린 `/opt/npm-tools/node_modules/playwright`, 크롬은 `/usr/bin/google-chrome`을 씀(다른 곳이면 스크립트 3·9째 줄 경로 고침)
- 작업 공간에서는 cdnjs가 막혀 있어 CDN 주소를 node_modules 파일로 바꿔 끼움(MAP). gate.js(관리자 잠금)는 빈 파일로 대신함
- 시험 구역은 스크립트 안의 가상 네모 구역(위도 37.46·경도 126.66, 200×170m) — 실제 구역 자료(유원 등)는 넣지 않음
- 결과 그림·PDF는 이 폴더에 생기며 커밋하지 않음(.gitignore)
