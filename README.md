# 정비사업 사업성 검토

재개발·재건축·가로주택정비사업의 구역 요건, 비례율, 조합원 분담금을 추정해 보는 웹 도구입니다. 빌드나 설치 없이 정적 파일만으로 동작합니다.

## 기능

1. **사업 개요**: 사업 유형, 용도지역, 용적률, 계획 연면적
2. **구역계**: 지도에서 다각형으로 구역을 그리면 면적을 자동 계산 (OpenStreetMap)
3. **조서·요건**: 토지조서와 건축물조서 입력·CSV 불러오기, 노후도와 유형별 요건 판단 (기준값은 편집 가능)
4. **분양수입**: 평형별 조합원·일반·임대·상가 분양수입 (종후자산)
5. **사업비**: 금액, 평당 단가, 공사비 대비 %, 총수입 대비 % 등으로 항목별 산정
6. **비례율·분담금**: 종전자산(공시지가 추정, 감정평가액, 조합원 합계), 비례율, 조합원별 권리가액과 분담금
7. **민감도**: 공사비와 일반분양가 변동에 따른 비례율 표와 차트

입력 내용은 브라우저에 자동 저장되며, 상단의 "파일 저장/열기"로 JSON 파일로 보관할 수 있습니다.

## 실행

`index.html`을 브라우저로 열거나, 로컬 서버로 띄웁니다.

```powershell
powershell -ExecutionPolicy Bypass -File serve.ps1
```

이후 http://localhost:8080 에 접속합니다.

## 주의

결과는 입력한 가정에 따른 추정치입니다. 노후도 기준(재개발 60%, 가로주택 2/3 등)과 노후 판정 연수는 법령과 관할 지자체 조례를 반드시 확인하고 수정해서 쓰세요.
