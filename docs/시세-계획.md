# 정비경매 리포트 — 시세 파악 계획 (2026-10-25 정리)

> 원칙: 경매는 **시세 파악이 핵심**이다. 시세가 정확하면 입찰가·내 돈·수익이 안정된다.
> 아파트는 비교적 쉽고, **빌라·상가 단타**가 목표인데 이쪽 시세가 어렵다 → 여기서 우리가 더 정확하면 경쟁은 적고 마진은 두껍다.

## 이미 반영된 것 (2026-10-24 ~ 25)
- [x] 중간값 대신 **닮은 거래 비교**(같은 단지·면적·층·연식·시점), 시점 보정, 닮은 거래끼리 폭 표시
- [x] 실거래에 없는 **집 상태**를 가격대로: 기본 상태(아래 25%) / 수리된 상태(위 20%). 경매 물건 = 기본 상태, 올수리 후 = 수리된 상태
- [x] **시세 성적표**(시세 화면): 최근 2개월 거래를 그 전 달 거래만으로 맞혀 오차·등급
- [x] 연립다세대 **매매** 실거래 수집 복구(RTMSDataSvcRHTrade2) — 2026-10-25 밤부터 1년치
- [x] 건물면적 없는 물건은 건축물대장 전유면적 사용, 공시가격 보충(필지번호 보정)
- [x] 호가: 매물 설명에서 상태(올수리·기본·급매)·저층 읽기, 기본 상태 호가×97%, 호가↔실거래 맞대기 경고
- [x] 호갱노노 웹은 매물 목록 없음(실거래만) → 네이버 부동산 매물 화면 사용

## 시세의 네 축
1. **매매 실거래** — 끝난 거래, 시세의 중심 (자동 수집)
2. **전월세 실거래** — 바닥(빌라는 전세 보수적으로) (자동 수집)
3. **매물·호가 + 호가 이력** — 지금 경쟁 상대, 집 상태, 시장 방향 (보신 화면만 저장 — 서버 자동 수집 안 함: 네이버 vs 다윈중개 판결)
4. **기준 시세** — KB시세(아파트 하위·일반·상위, 빌라 KB AI 시세), 부동산원 시세, 네이버 빌라 추정가(신뢰도 A~D) — 맞대 보기용, 성적표로 무게 결정

## 할 일 (순서)
1. [ ] 빌라 실거래 수집 확인 → **세 줄 시세표**(하위·일반·상위, KB와 같은 틀)
   - 빌라: 같은 건물 다른 호 거래 최우선 / 바닥 = 땅값(대지지분×공시지가)·전세 / 천장 = 주변 신축 빌라 분양가 / 매도가 상한 = 사는 사람 대출 기준(KB AI 시세)
2. [ ] **매물 자동 저장 크롬 확장**: 네이버 부동산 매물 화면을 열면 가격·면적·층·상태·등록일 자동 저장(관리자 전용) + **오늘 볼 매물 목록**(후보 물건의 같은 건물·같은 동·주변 상가 10~20곳)
3. [ ] **호가 이력 분석**: 사라진 매물 ↔ 이후 실거래 맞추기 → 지역·종류별 **호가→체결 할인율**, **팔리는 기간**, 호가 내림, 매물 적체
4. [ ] **상가 수익환원**: 가치 = 연 임대료 ÷ 지역 수익률. 임대료 = 현황조사서 임차인 월세, 공실이면 부동산원 상업용부동산 임대동향(공실률·임대료·수익률). 단타 = 공실 상가 사서 임차 맞춰 수익률 상품으로 매도. 법인 취득세 중과 없음(4.6%), 건물분 부가세
   - 필요: 공공데이터포털 "한국부동산원 상업용부동산 임대동향조사" 활용신청
5. [ ] 부동산원 R-ONE 주간 매매가격지수·매매수급동향(시장 방향) — 활용신청 필요
6. [ ] KB시세·부동산원·네이버 추정가 북마크/확장 읽기 → 성적표에 근거별 채점, **근거별 무게 자동 결정**
