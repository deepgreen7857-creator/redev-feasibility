# /urban 평형 구성 일반화 지시문 (노트북 Claude Code용)

## 배경
/urban 4탭(개략 건축계획)의 평형이 59·84·114로 고정돼 있어 중대형 위주로만 나온다.
가로주택정비사업·역세권 소형 단지처럼 39·49㎡만 짓는 구성도 있으므로 평형을 고를 수 있게 한다.
/arch는 이미 바꿔 놓았다(평형 칸을 `shared/criteria/arch.json`의 `평면` 키로 자동 생성, 프리셋 3종).

## 할 일
1. 평형 목록은 코드에 고정하지 말고 `shared/criteria/arch.json`의 `평면` 키(숫자 키: 39, 49, 59, 74, 84, 101, 114)에서 읽는다.
2. 4탭 평형 입력을 이 목록으로 만들고, 비율이 0이거나 빈 평형은 계산에서 뺀다.
3. `평형구성_예시`(재개발 일반 / 소형 위주(가로주택·역세권) / 중형 위주)를 버튼으로 둔다.
4. 예전에 저장된 59·84·114 값은 그대로 읽히게 한다(없는 평형은 0).
5. `JbsSite.applyUrbanPlan(key, plan)`에 넘기는 `plan.byType`은 `{전용㎡ 숫자: 세대수}` 형태 그대로 둔다.
   site-store 쪽은 이미 어떤 평형이든 60㎡ 이하 세대수, 85㎡ 이하·초과 전용면적 합계를 계산한다.
6. 사업성 계산(분양가·공사비 등)에 평형별 표가 있으면 새 평형도 같은 방식으로 늘린다.
   단가 값이 없는 평형은 0으로 넣지 말고 빈 칸 + "값 확인 필요"로 표시한다.
7. 법정 주차는 세대당 1대(전용 60㎡ 이하 0.7대) 하한이 적용되는지 39·49만 구성으로 확인한다.
