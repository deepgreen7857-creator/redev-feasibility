# 정비경매 리포트 — 전체 정리 (2026-10-25 기준)

사이트: www.jbslab.co.kr/auction · 서버: Firebase jbslab-auction · 코드: redev-feasibility(auction-web·auction-server·court-collector)
판단 규칙 고정판: **분석기 2026-10-25a** — 2~3주 성적을 본 뒤에 고친다.

---

## 1. 목표와 원칙

- **목표**: 명퇴(올해 말~내년 초) 전에 빌라·아파트(·상가) 단타가 실제로 수익이 나는지 **숫자로 확인**.
- **핵심은 시세**: 시세가 정확하면 입찰가·내 돈·수익이 안정된다. 시세 분석은 어디서도 해 주지 않으니 우리가 직접 하고, **성적표로 맞는지 증명**한다.
- **자료가 다 모이기 전에는 판정하지 않는다** — 빈칸을 감정가·기본값으로 메워 그럴듯한 숫자를 만들지 않는다.
- **자료는 한 가지씩 100% 받고 확인한 뒤 다음으로**.
- **유찰이 많거나 수익률이 터무니없으면 문제부터 의심**한다(유찰 8회↑, 수익률 500%↑).
- **원본 기준**: 대법원·온비드·국토부 원본. 다른 경매 사이트·네이버를 서버가 긁어 오지 않는다(네이버 vs 다윈중개 판결). 호가·KB시세는 **보신 화면만** 읽는다.
- **재직 중**: 반복 매매·법인 임원은 복무 문제 소지 → 실전 입찰은 감사실 확인 후, 법인은 명퇴 후. 관할(미추홀구) 정비구역 물건은 이해충돌 주의.

|---|---|---|

## 3. 판정 흐름 (물건 하나)

1. **자료 점검** — 최저가·감정가·면적·권리 원문(법원 명세서 / 공매 상세)·시세 근거(주거 실거래 3건↑, 토지 공시지가) 중 하나라도 없으면 **'자료 수집 중'**(판정·점수·수익·입찰가·일정표 제외). 주택 공시가격·공시지가는 보조(경고).
2. **시세** — 닮은 거래 비교 → **기본 상태 가격**(경매 물건 가치) / 수리된 상태 가격(올수리 후). 호가가 있으면 맞대 보기.
3. **비용·세금** — 취득세(법인 12% 중과, 수도권 공시가격 1억 이하·정비구역 밖은 제외), 명도·수리(지금은 고정값 → 범위로 바꿀 예정), 이자, 법인세.
4. **매수상한** = 가치 − 비용 − 마진.
5. **판정** — 지금 매력 / 유찰 대기 / 권리 확인 후 판단 / 가격 안 맞음 / 오류 의심 / 자료 수집 중.
   - 권리 확인 후 판단으로 보내는 경우: Claude 검토 보류·제외, 유찰 8회↑, 공매 원문 미수집 + 유찰 5회↑(또는 감정가 40%↓), 법원 명세서 미확인 + 3회↑ 유찰, 토지 같은 단지 실거래 없음.
   - 오류 의심(계산 이상): 수익률 500% 초과, 가치가 최저가 100배 초과.
6. **우리 입찰가** = 예상 낙찰가(최저가 × 같은 종류 '낙찰가÷최저가' 중앙값), 가산 폭 0%.
7. **회차별 진입** — 앞으로 10회차까지: 최저가 → 예상 낙찰가 → 남는 돈 × **그 회차까지 남아 있을 확률**(완료 물건 낙찰률) → 기대값 최대 회차. 공매는 공고상 실제 날짜, 법원은 5주 간격 추정.

## 5. 성적표 (판단이 맞았나)

| 성적표 | 위치 | 무엇을 재나 |
|---|---|---|
| 시세 성적표 | 성적 → 시세 | 최근 2개월 실거래를 그 전 달 거래만으로 맞힌 오차·등급(A ≤3%…F >12%), 근거 등급·층·동별, 크게 빗나간 거래 |
| 분석기 성적표 | 성적 → 완료 물건 | 예상 낙찰가(=입찰가) 오차·치우침·승률·승률 70%에 필요한 가산 폭 |
| 유찰 예측 성적표 | 성적 → 완료 물건 | '몇 회 더 유찰된 뒤 팔린다' 적중률, 남아 있을 확률 예측 vs 실제 |
| 판정 성적표 | 성적 → 완료 물건 | 종류·지역·실거래 근거별 적중률, 1회차 바로 낙찰·놓침 |

10-23 첫 측정(공매 215건, 사후 계산): 예상 낙찰가 오차 4.5~4.8%(C) — 아파트 2.6%·오피스텔·다세대·연립 B, 대지 F, 경쟁(2명↑) 물건은 실제가 +5.9% 높음.
진짜 성적은 **입찰 전 예측 기록**(매일 밤 11시 40분)이 기일을 지나면서 쌓인다.

## 6. 남은 일과 일정

### 시세를 뺀 나머지 (약 2주)
| 일 | 기간 |
|---|---|
| 권리분석 자동화(원문에서 말소기준·인수 금액·대항력 임차인, Claude 검토 연결) | 2~3일 |
| 명도·수리 비용 범위(좋음/보통/나쁨) — 대표 유형 견적 2~3개 받으면 숫자 교체 | 1일 |
| 검토서 근거 표시(출처 문서, 미확인 표시) | 1~2일 |
| 등기부 열람본 연결 | 1일 |
| 자료: 공매 원문 4~5일, 법원 명세서 1~2주 | 자동 |
→ ~11월 8일 자동화 완료, ~11월 말까지 규칙 고정하고 성적 확인.

### 시세 (계속)
1. 빌라 세 줄 시세표(하위·일반·상위) — 같은 건물 거래 최우선, 바닥=땅값·전세, 천장=주변 신축 분양가, 매도가 상한=KB AI 시세
2. 매물 자동 저장 크롬 확장 + 오늘 볼 매물 목록
3. 호가 이력 → 호가→체결 할인율, 팔리는 기간
4. 상가 수익환원(연 임대료 ÷ 지역 수익률), 부동산원 상업용 임대동향
5. 부동산원 R-ONE 시장 지표
6. KB·부동산원·네이버 추정가 맞대기 → 근거별 무게 자동
7. 우리가 잘 맞히는 구역 지도 → 단타 후보 구역
8. 중개사 확인값 입력 칸
