## 입찰 원칙
- 최저입찰가 = 그 회차 최저가 + 1만 원. 회차 이름은 최초 → 1회 유찰 → 2회 유찰로 부른다. 저감률은 30%(직전 최저가 × 0.7, 천 원 단위 절사).
- 최고입찰가 = (시세 하한 − 비용 − 목표수익) ÷ 1.011 − 인수금액.
- 진입 회차는 최저가가 처음으로 최고입찰가 아래로 내려오는 회차다.
- 선순위 보증금이 커서 유찰이 거듭돼도 해결되지 않는 물건만 제외한다. 공시가를 확인하기 전에 임의로 제외하지 않는다.
- 시세 파악이 핵심이다.
  - 시세가 확인된 물건을 최상위에 둔다.
  - 시세 검토 내용과 "결론이 뒤집히는 기준선(checkLine)"을 본문에 반드시 쓴다.
  - "근거 약함" 같은 표현은 쓰지 않는다.
- 저층 아파트는 Claude가 직접 확인해 평형별로 정리한다. 확인 항목: 평형 리스트, 건축물 정보, 호별 공시가, 매매·전세·월세 실거래.

- 부동산공시가격알리미(realtyprice.kr): 지번검색 → 단지 → 동·호 → 열람.
- 네이버부동산은 Claude Chrome에서 차단된다. apis.data.go.kr은 브라우저·VM 모두에서 막힌다.
- 노트북 VM의 $HOME/add_item.py는 JSON을 받아 id 기준으로 추가하거나 교체한다:
  `python3 $HOME/add_item.py items.json <<'EOF' ... EOF`
- 커밋은 사용자가 PowerShell에서 직접 한다(Claude가 device에서 git을 실행하면 lock 문제가 생긴다):
  ```
  cd C:\notedata
  git add review
  git commit -m "review: 업데이트"
  git push
  ```
  push가 거절되면 `git pull --no-rebase --no-edit` 후 다시 push한다.
